# Ever After Planner

A lightweight wedding planning dashboard for organizing:

- Venues and locations to book
- Guest list management
- Photography and video services
- DJ and music booking
- Wedding decoration styles and moodboard ideas

## Project structure

- `index.html` — main app layout
- `styles.css` — styling and branding
- `script.js` — sample wedding data and interactive logic

## Run locally

From the project folder, open `index.html` in a browser, or launch a simple local server:

```bash
cd wedding-planner-app
python3 -m http.server 8000
```

Then visit:

http://localhost:8000

## Features included

- Venue shortlist cards
- Guest list form with RSVP tracking
- Vendor booking sections for photography and DJ services
- Decoration style overview
- Responsive layout for easy editing later

This project is intentionally simple and editable so it can be expanded into a larger app later.
